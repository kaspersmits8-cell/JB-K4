# Data templates

Format examples only, one per file type, sketching the main scenario (Piet, January 2026, 70% processed vs 100% agreed).
They are internally consistent, so `DATA_DIR=docs/data-templates npm run data:check` must pass.

For the data author: copy this folder's structure into `data/`, then extend it with the ingredients in docs/DATA_CONTRACT.md §11.
For Codex: use these as the basis for small test fixtures in `tests/fixtures/`. Never copy them into `data/`.
