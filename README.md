# Trust Dossier

SD Worx hackathon prototype. Next.js App Router, TypeScript, SQLite, and deterministic evidence analysis.

Requires Node 24.13+ (24.x) and npm. Run `npm install`, then `npm run db:verify`.
`npm run dev` starts the app; `npm test`, `npm run typecheck`, and `npm run lint` run checks.

Implementation is in progress. Never write application-generated content into `data/`.
